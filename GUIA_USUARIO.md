## 🔬 Realizar un Diagnóstico

### Paso 1: Iniciar el Diagnóstico

1. Toca el botón **"Realizar Diagnóstico"** en la pantalla principal
2. Se abrirá el wizard de diagnóstico paso a paso

*[Imagen: Botón de diagnóstico - 400x200px]*

### Paso 2: Tomar o Seleccionar Foto

1. **Tomar foto:** Toca el ícono de cámara para tomar una nueva foto
2. **Seleccionar foto:** Toca el ícono de galería para elegir una foto existente
3. Asegúrate de que la foto muestre claramente la parte afectada del cultivo

*[Imagen: Pantalla de selección de imagen - 600x400px]*

### Paso 3: Proporcionar Información

Completa los siguientes campos:
- **Descripción:** Describe los síntomas observados
- **Ubicación:** La ubicación se detecta automáticamente
- **Etapa del cultivo:** Selecciona la etapa actual de tu cultivo

*[Imagen: Formulario de información - 800x600px]*

### Paso 4: Procesamiento

1. Toca **"Finalizar Diagnóstico"**
2. La aplicación procesará la imagen con inteligencia artificial
3. Espera unos segundos mientras se analiza

*[Imagen: Pantalla de procesamiento - 600x400px]*

### Paso 5: Resultados

El sistema te mostrará:
- **Enfermedad identificada**
- **Nivel de confianza** (porcentaje)
- **Recomendaciones de tratamiento**
- **Detalles adicionales**

*[Imagen: Pantalla de resultados - 800x600px]*

### Paso 6: Creación Automática del Caso

- El diagnóstico se guarda automáticamente
- Se crea un caso de seguimiento
- Serás dirigido al detalle del caso recién creado

*[Imagen: Caso creado automáticamente - 600x400px]*

## 📋 Gestionar Casos

### Ver Mis Casos

**Desde la pantalla principal:**
1. Desplázate por el carrusel de "Mis Casos Activos"
2. Toca cualquier caso para ver los detalles

**Desde el menú:**
1. Toca el menú hamburguesa (☰)
2. Selecciona "Mis Casos"

*[Imagen: Carrusel de casos activos - 1000x300px]*

### Detalles del Caso

En la página de detalles verás:
- **Información del caso:** Nombre, estado, fechas
- **Diagnóstico:** Enfermedad, confianza, recomendaciones
- **Imágenes:** Fotos del diagnóstico
- **Registros:** Historial de actividades

*[Imagen: Detalle de caso - 800x1000px]*

### Estados de Caso

- **🟢 Activo:** Caso en seguimiento
- **🔴 Cerrado:** Caso finalizado
- **🟡 En Proceso:** Caso siendo evaluado

## ❓ Preguntas Frecuentes

### ¿Cómo funciona el diagnóstico?

AgroDoctor utiliza inteligencia artificial entrenada específicamente para identificar enfermedades comunes en cultivos centroamericanos. Simplemente toma una foto clara de la parte afectada y el sistema te dará un diagnóstico con recomendaciones.

### ¿Qué tan preciso es el diagnóstico?

El sistema muestra un porcentaje de confianza para cada diagnóstico. Si el porcentaje es alto (>70%), el diagnóstico es muy confiable. Si es medio (50-70%), considera consultar con un especialista.

### ¿Puedo editar mis casos?

Sí, desde el detalle de cada caso puedes:
- Cambiar el nombre del caso
- Modificar el estado
- Agregar notas adicionales

### ¿Cómo contacto a los proveedores del marketplace?

Cada producto en el marketplace incluye información de contacto del proveedor. Puedes contactarlos directamente para realizar compras.

### ¿Mis datos están seguros?

Sí, todos tus datos están protegidos con autenticación segura y almacenados en Firebase con las mejores prácticas de seguridad.

### ¿Puedo usar la aplicación sin conexión?

La aplicación requiere conexión a internet para:
- Realizar diagnósticos
- Sincronizar datos
- Acceder al marketplace

Sin embargo, puedes ver información previamente cargada sin conexión.
